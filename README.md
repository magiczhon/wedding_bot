# wedding_bot — сервис приглашений на свадьбы для Telegram и ВКонтакте

Один бот обслуживает сколько угодно мероприятий. Гости открывают приглашение по ссылке или коду и отвечают в привычном мессенджере. Организаторы ведут свои мероприятия в веб-панели, а владелец сервиса видит всё и управляет тарифами.

## Возможности

**Гости**
- Открывают приглашение по ссылке (`t.me/<бот>?start=ev_КОД`, `vk.me/<сообщество>?ref=ev_КОД`) или сообщением `код КОД`.
- Перед регистрацией дают согласие на обработку персональных данных, «🔒 Мои данные» показывает, что хранится.
- Команда `/delete` удаляет всё и отзывает согласие.
- Подтверждают присутствие и число человек, выбирают блюда и напитки на себя и спутников.
- Смотрят место с картой, дресс-код и программу.
- Кнопками «🎤 Вопрос ведущему» и «✉️ Связь с организатором» пишут напрямую, ответ приходит в тот же чат.

**Команда** (организатор, молодожёны, ведущий, декоратор, свет, видео, фото…)
- Присоединяется по коду своей роли.
- Один человек может работать на нескольких свадьбах сразу: переключается кнопкой «🔄 Мои мероприятия», а сообщения из других мероприятий приходят с подписью `[Название]`.
- Общается в рабочих чатах по ролям, например «Декор» = организатор + молодожёны + декоратор, и так же со светом, видео и ведущим. Сообщения пересылаются между Telegram и ВКонтакте.
- Ведущий отвечает гостям ответом на сообщение или командой `ответ N текст` и может написать всем гостям с подтверждением.

**Веб-панель** (`http://127.0.0.1:8080`)
- **Обзор:** гости, сколько придут с учётом спутников, доля ответивших, ответы, блюда, напитки, мессенджеры, новые гости по дням, ссылки для гостей.
- **Гости:** фильтр по ответу, поиск, пожелания; удаление данных гостя по его просьбе.
- **Команда:** кто подключился, коды ролей, выпуск нового кода вместо утёкшего.
- **Сообщения:** журнал вопросов гостей, рабочих чатов и рассылок.
- **Рассылка:** всем гостям, тем, кто придёт, тем, кто не ответил, команде или организаторам для проверки. Ответы гостей приходят организаторам в бот.
- **Настройки:** все тексты, место и координаты, меню, роли, каналы и чаты (YAML с проверкой), архивация, удаление мероприятия.
- **Выгрузка в Excel:** гости, пожелания, команда, сообщения.
- **Для владельца сервиса:** статистика по всем мероприятиям, аккаунты организаторов, лимит гостей и владелец каждого мероприятия. Лимит нужен для тарифов: новые мероприятия организаторов получают `default_guest_limit`.

## Запуск

```bash
pip install -r requirements.txt
cp config.example.json config.json            # токены, веб-панель, оператор ПДн
python manage.py create-admin owner --name "Иван"   # первый аккаунт веб-панели, спросит пароль
python main.py                                 # бот + веб-панель
```

Дальше: войдите в панель → «Новое мероприятие» → проверьте «Настройки» → отправьте гостям ссылку из «Обзора», а команде — коды из вкладки «Команда». Организаторам создайте аккаунты во вкладке «Аккаунты» (или `python manage.py create-organizer login`).

### config.json

| Ключ | Что это |
|---|---|
| `telegram.token` | токен бота от [@BotFather](https://t.me/BotFather) |
| `vk.token`, `vk.group_id` | ключ сообщества и его id (настройка ниже) |
| `web.host`, `web.port` | где слушает панель; по умолчанию только локально `127.0.0.1:8080` |
| `web.secret_key` | длинная случайная строка для подписи сессий — обязательно задайте |
| `web.public_url` | внешний адрес панели; из него строится ссылка на политику `…/privacy` |
| `web.https` | `true`, если панель открывается по HTTPS (куки только по защищённому соединению) |
| `privacy.operator`, `privacy.contacts` | кто оператор персональных данных и как с ним связаться — показывается в согласии |
| `privacy.retention` | срок хранения данных, показывается в согласии |
| `privacy.version` | увеличьте, если изменили условия, — бот попросит согласие заново |
| `default_guest_limit` | лимит гостей для мероприятий, созданных организаторами (пусто — без лимита) |

Любой из мессенджеров можно не указывать.

### Публикация панели в интернет
Панель слушает только `127.0.0.1`. Для внешнего доступа поставьте перед ней nginx или Caddy с HTTPS и укажите `web.public_url` и `"https": true`. Для одного сервера со свадьбами встроенного сервера достаточно.

### Telegram
Создайте бота у @BotFather и вставьте токен в `telegram.token`.

### ВКонтакте
1. Создайте сообщество, в «Управление → Сообщения» включите сообщения сообщества.
2. «Работа с API → Ключи доступа» — ключ с правами «сообщения сообщества», «фотографии», «документы».
3. «Работа с API → Long Poll API» — включите, версия 5.199, событие «Входящее сообщение».
4. «Сообщения → Настройки для бота» — включите «Возможности ботов».
5. Впишите ключ и id сообщества в `vk.token` и `vk.group_id`.

## Персональные данные

- Бот не сохраняет имя и ответы, пока человек не нажмёт «✅ Даю согласие». Согласие называет оператора, состав данных, цель, срок и способ отзыва, а ссылка ведёт на страницу `/privacy`.
- Все согласия, отказы и отзывы пишутся в журнал `consent_log`. Он хранится и после удаления данных как подтверждение.
- `/delete` в боте и «Удалить данные» в панели удаляют имя, ответы, пожелания и сообщения. Человек, который больше нигде не участвует, удаляется полностью. Удаление мероприятия удаляет все его данные.
- Страница `/privacy` — это **шаблон**. Перед запуском проверьте её с юристом.
- Для работы с ПДн нужно уведомить Роскомнадзор, а данные граждан РФ хранить на сервере в России.

## Переход со старой версии

При первом запуске `main.py` данные прежней версии для одной свадьбы (любой из двух) переносятся в новое мероприятие. Настройки берутся из `event.yaml`, если он есть. Организаторы из `admins` в `config.json` становятся организаторами этого мероприятия.

Затем:
- создайте аккаунт владельца (`manage.py create-admin`) и в «Настройках» назначьте мероприятию владельца;
- после обновления бот один раз попросит у всех согласие на обработку данных.

Перенос можно запустить и вручную: `python manage.py import-legacy --event event.yaml`.

## Структура

```
main.py                 запуск: мессенджеры и веб-панель в отдельных потоках
manage.py               аккаунты веб-панели и перенос старой базы
core/bot.py             логика бота: мероприятия, согласие, гости, команда, рассылки
core/event_config.py    шаблон настроек мероприятия и их проверка
core/messenger.py       интерфейс мессенджера; новый мессенджер (например, MAX) = новый адаптер
core/export.py          выгрузка в Excel
adapters/               Telegram (pyTelegramBotAPI) и ВКонтакте (vk_api)
web/app.py, templates/  веб-панель на Flask
database/db.py          SQLite: мероприятия, люди, участие, ответы, журналы
event.example.yaml      шаблон настроек нового мероприятия
tests/                  pytest: сценарии бота, веб-панель, адаптеры
```
