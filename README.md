# wedding_bot — бот-приглашение на свадьбу для Telegram и ВКонтакте

Один бот работает сразу в двух мессенджерах: гости пишут где им удобно, а организатор видит всех в одной таблице.

**Для гостей**
- регистрация по имени и подтверждение присутствия: «приду», «не смогу», «пока не знаю» и сколько человек;
- пожелания по еде и напиткам на себя и спутников; повторная анкета обновляет ответ, а не создаёт дубль;
- место, время, карта, дресс-код, программа;
- «🎤 Вопрос ведущему» и «✉️ Связь с организатором»: ответ приходит в тот же чат с ботом.

**Для ведущего**
- получает вопросы гостей, отвечает конкретному гостю ответом на сообщение (reply) или командой `ответ 12 текст`;
- «📢 Написать гостям» — сообщение всем гостям сразу, с подтверждением перед отправкой; ответы гостей приходят ведущему.

**Для команды** (организатор, молодожёны, ведущий, декоратор, свет, видео, фото…)
- рабочие чаты по ролям: «Декор» = организатор + молодожёны + декоратор, «Свет», «Видео», «Ведущий», общий чат команды;
- сообщение участника получают все остальные участники чата, даже если они в другом мессенджере. Внутри Telegram пересылается всё, включая голосовые и видео; между Telegram и ВКонтакте — текст, фото и файлы;
- ответ (reply) на сообщение из чата уходит обратно в этот чат, даже если вы сейчас в другом;
- при входе в чат видно участников, кто ещё не подключился, и последние сообщения.

**Для организатора**
- «🔑 Приглашения команды» — коды и ссылки, по которым подрядчики присоединяются со своей ролью;
- «📋 Выгрузка гостей» — Excel с листами «Гости», «Пожелания», «Команда», «Сообщения»;
- «📊 Сводка» — сколько придут, сколько не ответили, что заказали;
- «📨 Рассылка» — всем гостям, тем, кто придёт, тем, кто не ответил, команде или тестовым пользователям; с подтверждением;
- «👤 Меню гостя» — посмотреть бота глазами гостя.

## Запуск

```bash
pip install -r requirements.txt
cp config.example.json config.json   # токены и админы
cp event.example.yaml event.yaml     # тексты, меню, роли и чаты
python main.py
```

### config.json — секреты

```json
{
    "db_name": "guests.db",
    "telegram": {"token": "TELEGRAM_BOT_TOKEN"},
    "vk": {"token": "VK_COMMUNITY_TOKEN", "group_id": 123456789},
    "admins": {"telegram": [111111111], "vk": [222222222]},
    "test_users": {"telegram": [111111111]}
}
```

- Любой из мессенджеров можно не указывать — запустится только настроенный.
- `admins` — id организаторов в каждом мессенджере, они получают роль «Организатор» автоматически.
- Старый формат (`token_id`, `admin_ids`, `test_users_id`) тоже читается, а база прежней версии переносится при первом запуске.

### Telegram
Создайте бота у [@BotFather](https://t.me/BotFather) и вставьте токен в `telegram.token`. Свой id можно узнать, например, у @userinfobot.

### ВКонтакте
1. Создайте сообщество (можно закрытое), в «Управление → Сообщения» включите сообщения сообщества.
2. «Управление → Работа с API → Ключи доступа» — создайте ключ с правами «сообщения сообщества», «фотографии» и «документы».
3. «Работа с API → Long Poll API» — включите, версия API 5.199, в «Типах событий» отметьте «Входящее сообщение».
4. В «Сообщения → Настройки для бота» включите «Возможности ботов» и кнопку «Начать».
5. Укажите ключ и id сообщества в `vk.token` и `vk.group_id`. Свой id ВКонтакте — число из ссылки vk.com/id….

### event.yaml — всё, что видят гости и команда
Тексты, адрес и координаты, программа, варианты еды и напитков, роли команды, каналы для гостей и рабочие чаты. Код менять не нужно: добавить, например, флориста — это строка в `roles` и новый чат в `rooms`.

## Как подключить команду
1. Организатор нажимает «🔑 Приглашения команды» и получает код на каждую роль.
2. Отправляет код подрядчику. В Telegram достаточно открыть ссылку `t.me/<бот>?start=join_КОД`, во ВКонтакте — написать сообществу `код КОД`.
3. Подрядчик пишет своё имя, получает доступ к своим рабочим чатам, а организатор — уведомление.

## Структура

```
main.py                  запуск: читает конфиги, стартует мессенджеры в отдельных потоках
core/bot.py              вся логика, не зависит от мессенджера
core/messenger.py        интерфейс мессенджера; новый мессенджер = новый адаптер с этими методами
core/export.py           выгрузка в Excel
adapters/telegram_adapter.py, adapters/vk_adapter.py
database/db.py           SQLite: пользователи, ответы, пожелания, приглашения, журнал сообщений
tests/                   сценарные тесты ядра и тесты адаптеров (pytest)
```

Чтобы добавить MAX, достаточно написать `adapters/max_adapter.py` с методами из `core/messenger.py` и подключить его в `main.py`. Учтите, что публиковать ботов в MAX могут только юрлица, ИП и самозанятые — резиденты РФ.
